TRADE WITH PUSHKAR RAJ — VERCEL DEPLOYMENT

Files:
- index.html
- assets/pushkar-profile.jpg

Deploy:
1. Open https://vercel.com and sign in.
2. Create a new project and import a Git repository containing these files, OR install Vercel CLI and deploy this folder.
3. Keep index.html at the project root and the photo inside assets/ as supplied.
4. No build command is required for this static HTML page.

Before publishing, update these placeholders in index.html:
- href="YOUR_TELEGRAM_LINK" with your real Telegram channel/invite URL.
- href="#" on the agency contact link with the correct contact URL (or remove the link if not needed).

The added timer counts down to the next weekday 09:15 AM IST market opening. It is a schedule countdown, not live market data. Public holidays are not currently excluded.
